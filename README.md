# CodeC Technologies – Python Developer Internship Projects

This repository contains two Python projects developed as part of my one-month Python Developer Internship at CodeC Technologies. These projects helped me gain practical experience in Python programming, web development, text processing, and application development.

## 📂 Projects

### 1. Automated Resume Parser

**Description:**  
A web application built using Python and Flask that extracts text and email addresses from uploaded PDF resumes.

**Features:**
- Upload resumes in PDF format.
- Extract text from PDF files.
- Identify email addresses using regular expressions.
- Display extracted information on a webpage.

**Technologies Used:**
- Python
- Flask
- PDFPlumber
- HTML
- CSS
- Regular Expressions

### 2. AI-Powered Chatbot

**Description:**  
A web-based chatbot built using Python and Flask that responds to common questions about Python, internships, and technical skills.

**Features:**
- Interactive chat interface.
- Responds to predefined questions.
- Handles user messages through a Flask API.
- Displays chatbot responses dynamically.
- Provides a simple customer-support-style experience.

**Technologies Used:**
- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON

## ⚙️ Installation and Setup

### Prerequisites
- Python 3 installed
- Visual Studio Code or another code editor
- A web browser

### Run the Automated Resume Parser

1. Navigate to the resume parser project folder.
2. Install the dependencies:

   ```bash
   pip install flask pdfplumber
   ```

3. Run the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000/` in your browser.

### Run the AI-Powered Chatbot

1. Navigate to the chatbot project folder.
2. Install Flask:

   ```bash
   pip install flask
   ```

3. Run the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000/` in your browser.

**Note:** Run only one Flask application at a time if both use the same default port.
